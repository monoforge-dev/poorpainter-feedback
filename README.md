# Poor Painter feedback

Issues for [Poor Painter](https://pp.monoforge.dev), a Piet code golf site. The site's source code is not here.

- **Delete your data:** open a [data deletion request](../../issues/new?template=data-deletion.yml). Your GitHub user and all your submissions are deleted. See the [privacy page](https://pp.monoforge.dev/privacy) for what is stored.
- **Bugs and suggestions:** open a [bug report](../../issues/new?template=bug.yml) or a blank issue.

---

[Poor Painter](https://pp.monoforge.dev)（Piet のコードゴルフのサイト）の問い合わせ用のリポジトリです。サイトのソースコードはここにはありません。

- **データの削除:** [削除の依頼](../../issues/new?template=data-deletion.yml)を開いてください。GitHub のユーザーと、すべての提出を消します。保存しているものは[プライバシーのページ](https://pp.monoforge.dev/privacy?lang=ja)を見てください。
- **不具合・要望:** [不具合の報告](../../issues/new?template=bug.yml)か、空の issue を開いてください。
